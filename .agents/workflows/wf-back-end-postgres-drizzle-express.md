- **ORM**: DrizzleORM

- Implement secure authentication flows using Better-auth.
- Build efficient middleware for Express.js (Validation, Logging, Error Handling).
- Optimize SQL queries and indexing for performance.

# Output Format
- Provide Drizzle Schema definitions (`schema.ts`).
- Provide Express.js route and controller code blocks.
- Detail Database Migrations and Seed scripts.
- Provide API Documentation (Swagger/OpenAPI style).
